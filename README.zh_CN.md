# 荒坂员工牌 (Arasaka Personnel Badge) · AI Passport

> 硬件平台：FoloToy AI Passport (ESP32-C3 · 8 MB Flash · 240 × 320 ST7789 显示屏 · 三物理按键 · ES8311 音频 · CW2017 电量计)  
> 固件版本：**v2.7.1**

基于赛博朋克荒坂企业风格打造的智能全功能工牌系统。集成 **6 款内置主题化小程序**、**全套小智 AI 语音交互与 19 项设备控制工具**、**多套矢量情绪表情**、**5 套独立本地身份卡槽** 及 **离线 Web 端侧配置套件**。

页面与选项切换采用 160ms 扫描线视觉反馈，告别多余延迟与虚假动效。全部界面文字、矢量图案与排版深度针对 240 × 320 竖屏优化。

### 1. 六款主题化内置小程序 (Mini Apps)

所有内置小程序均由系统统一管理生命周期，实时自适应当前工牌的 5 色主题配色方案（背景色、面板色、强调色、主文字色、辅文字色）：

| 小程序 | 标识 (ID) | 功能与特色 | 核心按键操作 |
| --- | --- | --- | --- |
| **Muse** | `muse` | 接入 Muse Gadget，支持运行时填写 SDK Token/代理、手机配对、按住说话发送语音便笺、分页显示文字回复，并复用小智矢量形象元素但独立保存 Muse 风格。凭证只保存在本机 NVS，不编译进固件。 | **按住上键**：录音<br>**松开上键**：发送<br>**下键**：取消本地等待<br>**OK**：确认/重试/翻页<br>**长按下键**：重置 Muse 配对 |
| **敲木鱼** | `zen-muyu` | 矢量敲击动画与解压音效，支持手动敲击与自动连敲；4 档节奏循环；数据持久化保存到 NVS，断电重启不丢失累计功德。 | **OK**：敲击<br>**上键**：切换自动/手动<br>**下键**：切换节奏 (30/60/80/120 次/分)<br>**长按上**：暂停并保存<br>**长按下**：切换音量 (0/20/40/60/80%) |
| **音效钥匙扣** | `voice-keychain` | 精选 25 个音频分类、709 段音频；“高燃BGM”位于首个分组，曲目只显示歌名。独立轻量解码器支持打断即播不积压，长歌名平滑滚动显示。 | **上下键**：选分类/选音效<br>**OK**：进入/播放<br>**长按上**：音量设置<br>**长按下**：停止播放 |
| **城市电台** | `leo-radio` | 集成 LEO Radio 在线收音机，连上 Wi-Fi 即可流式播放国内外精选城市广播频道；支持断点记忆频道。 | **上下键**：快速切台<br>**OK**：播放 / 暂停<br>**长按上**：网络与电台设置 |
| **赛博摇卦** | `cyber-yao` | 基于 CyberYAO 六爻周易起卦模型；投掷 3 枚铜钱自下而上成卦；支持本卦/之卦/动爻/卦爻辞滚屏阅读；支持基于 IP 经度的**真太阳时天文校准**；可一键唤醒小智白话解读。 | **OK**：投掷铜钱成爻 / 结果页呼出小智解读<br>**上下键**：滚屏浏览卦爻辞原文<br>**长按下**：清空重新起卦 |
| **圣杯决策** | `holy-cup` | 传统民间投掷杯筊决策游戏。默念问题后投掷两个杯筊，以一正一反为「圣杯（可行）」、双正为「笑杯（再问）」、双反为「阴杯（暂缓）」；矢量立体杯筊渲染，带投掷次数统计。 | **OK**：再掷一次<br>**长按 OK**：退出返回小程序列表 |

> **全局二级菜单通用退出规则**：在任意小程序或系统子页面中，**长按 OK 键**均会呼出统一步骤菜单：**返回上一级 / 回到首页 / 继续当前页面**，杜绝误触丢进度。

### 2. 小智 AI 语音大模型交互 (XiaoZhi AI)

通过独立页面（**员工终端 → 系统设置 → 小智 AI**）或**工牌首页长按上键**即可快速开启全功能小智语音对话：

- **半双工流式自然对话**：说完自动侦测发送，收到回复即时流式播放，按 OK 即可随时打断抢话。
- **252 款多风格矢量表情 (Face Clock)**：
  - 支持 4 套可切换风格：**圆萌精灵**、**男生头像 (带高光光头)**、**女生头像 (波波头与发饰)**、**公路之王 (King of the Road)**。
  - 每套风格包含 21 种情绪变体，每种情绪拥有 3 款细分造型（共 63 姿态/套，总计 252 种精细表情）。
  - 嘴形由实时 PCM 输出振幅驱动，表情数据采用行索引无损 RLE 压缩解码，内存极低。
  - 对话中**长按上键**可轮换保存表情风格，**长按下键**直达小智设置。
- **19 项内置 MCP 设备控制与联动工具**：
  小智云端支持识别并直接调用本工牌的硬件接口，实现全语音控制：
  1. `self.get_device_status`：查询电量、Wi-Fi、屏幕亮度、当前与所有已配置工牌编号和姓名。
  2. `self.apps.open`：语音启动指定小程序（木鱼、电台、钥匙扣、摇卦、Muse）。
  3. `self.audio.search` / `self.audio.play` / `self.audio.play_random`：搜索音效、播报指定 ID 或随机播一段音效。
  4. `self.badge.show_qr`：语音立即展示当前工牌二维码并退出对话。
  5. `self.badge.switch`：根据编号 (1~5) 或姓名切换当前激活工牌。
  6. `self.display.set_brightness`：语音调节屏幕背光亮度 (20% ~ 100%)。
  7. `self.xiaozhi.set_volume`：单独调整小智语音回复音量 (0 ~ 100%)。
  8. `self.radio.search` / `self.radio.play`：搜索精选网络电台并即刻启播。
  9. `self.reminder.set` / `get` / `cancel`：管理多达 8 条持久闹钟提醒，支持秒级倒计时、北京时间钟点、日历日期、工作日/周末重复周期。
  10. `self.yao.cast` / `self.yao.get`：语音直接起卦并调用易经本卦/之卦全文字段给出通俗生活建议。
  11. `self.badge.get_profile` / `update_profile`：语音直接修改当前工牌的姓名、部门、职位等文本信息。
  12. `self.system.action`：执行回到首页 (`home`) 或安全深度睡眠关机 (`shutdown`)。

### 3. 多工牌系统与无网配置工具 (5 Badge Profiles)

工牌支持保存 **5 张完全独立的身份卡片**，每张均独立保存自定义姓名、职位、部门、员工编号、头像照片、品牌 Logo 及专属配色方案。

- **快速切换**：在工牌首页**长按 OK 键**即可呼出工牌卡片选择器，上下键选择并瞬间切换，重启自动保持最后激活的工牌。
- **配置工具 (`configure/index.html`)**：
  - **USB Web Serial 直连**：使用 Chrome/Edge 浏览器打开离线网页，插入 USB 数据线即可连接。免驱动、免装软件、数据不出本地，完全不上云。
  - **手机热点免线配置**：若无电脑，在工牌进入 **系统设置 → 网络设置** 按 OK 开启临时热点，手机连接工牌 Wi-Fi 后访问 `http://192.168.4.1`，即可通过手机浏览器完成全部相同配置。
  - **图片与排版自适应**：支持上传最大 10 MB 的个人照片与微信二维码图片，页面自动裁切为 72 × 88 头像及高精细度单色二维码，自动分行排版。
  - **Muse 配置**：保存设备主人提供的 Muse SDK Token 和可选局域网 HTTP 代理，Token 不回传浏览器。更换 Token 会清除旧 Muse 配对；只改代理会保留配对。

## 存储分区与固件架构

系统针对 ESP32-C3 (8 MB Flash，无 PSRAM) 进行了深度优化与安全隔离：

- **Flash 分区表设计**：
  - `factory` (应用固件区)：`3.75 MiB` (0x3C0000 字节，起始于 0x10000)
  - `voice_data` (音效首段)：`2.75 MiB` (起始于 0x3D0000)
  - `voice_tail` (音效尾段)：`512 KiB` (起始于 0x750000)
  - `badge_slots` (工牌 2~5 槽位)：`768 KiB` (0xC0000 字节，起始于 0x690000)
  - `badge_user` (工牌 1 槽位)：`192 KiB` (0x30000 字节，起始于 0x7D0000)
  - `nvs` / `otadata` / `phy_init` 保留在安全基线地址。
- **资料防丢升级**：每个工牌槽位均采用 A/B 双份 96 KB 备份与校验和验证，即使固件全量升级或写途中断电，原有的个人信息、头像图片及 Wi-Fi 配置均可完整保留。

## 编译与安装说明

### 环境准备
- **ESP-IDF**：v5.5.3 (已激活环境)
- **编译依赖**：Python 3、Git、CMake、Ninja

### 静态验证与编译
```bash
# 1. 执行静态规则与资源覆盖校验
python tools/check_repo.py

# 2. 编译固件
idf.py -B build -D SDKCONFIG=build/sdkconfig build

# 3. 生成全量固件镜像并执行一致性校验
idf.py -B build merge-bin -o FoloToy-AI-Passport-full.bin
python tools/verify_firmware.py build
```

### 烧录固件
```bash
# 分段烧录应用（推荐，保留现有工牌资料与 NVS 存储）：
idf.py -p COM6 flash monitor

# 如需使用全量保护工具（自动备份现有 Flash 并校验音效资源）：
python tools/flash_badge.py --port COM6 --backup-dir ./my_backup
```
