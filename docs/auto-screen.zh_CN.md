# 自动息屏

从首页菜单进入“设置 → 自动息屏”，通过上下键选择常亮、30 秒、1 分钟（默认）、
2 分钟或 5 分钟，按 OK 确认保存，重启后仍然有效。长按 OK 直接返回设置，
不保存尚未确认的选项，保留原设置。该设置对所有页面生效，不依赖是否开启小智后台唤醒。

小智正在聆听、思考、回复时保持亮屏；后台等待唤醒词不阻止息屏，识别到唤醒词后
亮屏并进入小智。息屏后的第一次实体按键操作仅用于唤醒，下一次操作才作用于页面。
提醒到期也会亮屏。息屏不会暂停电台或音效库的播放。

只有系统任务负责屏幕、背光、LVGL 的暂停与恢复以及显示性能锁。音频工作任务独占
管理音频芯片，并持有独立的播放性能锁；暂停或无声 15 秒后关闭收发通道并释放锁，
再次播放先恢复性能和音频硬件。退出音频应用立即关闭通道。停留在小程序页面本身
不再阻止轻睡眠，开机后从未播放也会先让音频芯片进入休眠。

2.6.26 将普通息屏且无音频工作时的 Wi-Fi 改为 MAX modem sleep，保持网络连接。
播放或对话恢复响应优先策略。后台语音唤醒开启时仍持续采集和检测，并保留所需
性能，不能同时获得关闭麦克风时的低耗电；木鱼自动敲击、电台播放、音效播放也不会
因为熄屏被中断。木鱼和音效库静默息屏时减少任务轮询，并跳过无用的界面刷新。

是否允许连接 Wi-Fi 不依赖当前页面或 modem sleep 策略。按键／唤醒探测会合并，并在新的客户端连接尝试后保留 15 秒宽限期，避免连续导航反复断开并扫描同一次连接。小智静默／忙碌以及息屏待机均可请求探测。配网热点开启时仍有意暂停自动漫游／重试以保护配置连接，但配置页主动扫描／连接请求不受影响。

只读 USB `info` 响应中的 `power` 提供屏幕、音频休眠和应用性能锁状态，
`wifi.powerSave` 提供实际配置的 Wi-Fi 省电模式；查询不会亮屏。该快照不代表电流测量。
当前配置启用 USB 连接保护，目的是在连接电脑时阻止自动轻睡眠。但一次实机诊断中，
息屏后 USB 查询中断，COM 口仍然可见；枚举到端口并不代表诊断通道仍然可用。
采集前须验证实际响应，受影响的 USB 会话可临时保持亮屏，诊断结束后恢复正常行为。
该观测不表示 USB／低功耗路径已经修复。最终续航和静态电流应在断开电脑 USB 后测量。
热点开启期间的功耗也不能按普通
Wi-Fi 客户端待机估算。

选择保存在 `cyber_badge_v1` NVS 的 `screen_timeout` 键中。缺失或异常值回退为
1 分钟，不清空现有数据。保存失败时保留原有生效设置，并停留在选择页。

验证：`tests/test_badge_power.c` 覆盖档位和计时边界；
`tests/test_badge_power_runtime.c` 使用模拟时间、屏幕和音频测试真实电源协调代码，
覆盖唤醒重试、任务交接与麦克风恢复；`tests/test_badge_navigation.c` 覆盖选择、
确认和取消；`tests/test_badge_network_runtime.c` 覆盖探测宽限期、开机尝试去重、
不依赖页面的省电策略及配网热点隔离。
