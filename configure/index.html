05小智 AI 后端

默认使用小智官方服务。需要接入自建或兼容后端时，在这里填写服务发现地址；留空并保存即可恢复官方默认。

自定义后端需要兼容小智官方 OTA / 服务发现返回格式。保存时小智不能正在运行；保存后下次连接小智生效。

06Muse 语音助手

先在 Muse Gadget 官网获取本人 SDK Token。Token 只写入设备且不会回显；留空保存表示保留原 Token。Muse 复用小智的形象元素，但风格选择独立保存。设备可直连时不要填写代理。

连接工牌后读取 Muse 配置状态。

保存配置时请先退出 Muse 小程序。更换 Token 会清除旧账号配对；只修改代理不会解除配对。配对需在手机 Muse 的开发者模式中添加屏幕显示的 MuseGadget 设备并按 OK 确认。

07辅助功能说明

六爻时间：联网后自动校时，并尝试用网络定位估算真太阳时；获取不到位置时直接使用北京时间，不影响起卦。状态会显示在起卦程序内，解读时会把成卦时间、校准状态和卦象一起传给小智。

连接工牌后读取自动定位与时间状态。

NFC：用安卓 NFC 写入应用（如 NXP TagWriter）写入一个网址，之后手机碰一碰工牌即可打开。NFC 网址由手机写入，不随员工牌切换变化，也不通过“保存到工牌”写入。
