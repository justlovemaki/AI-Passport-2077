# 配置页导入与导出

USB/热点配置页的第 **07 配置导入/导出** 提供“导出全部配置”和“导入并覆盖配置”。
在整包安装或主动擦除前后使用。常规固件更新仍应优先使用
[保留数据升级流程](preserving-upgrade.zh_CN.md)。

操作不经过云端。同一份内嵌/离线页面既支持电脑 Web Serial，也支持连接工牌热点后的
手机浏览器。浏览器在本机加密并下载 `.aipcfg` 文件。Wi-Fi 密码与 AI 凭证不会显示在
表单中，也不会由普通设置读取接口返回。

## 包含范围

网页备份包含：

- 工牌已持久化 NVS 的一致性 24,576 字节快照：已保存 Wi-Fi/密码、当前工牌、
  显示/息屏偏好、小智/Muse 凭证与配对、应用偏好/计数和提醒；
- 五张工牌各自当前有效的已提交内容：资料、主题、照片、品牌、图标与二维码，
  并保留每张工牌的资料格式；
- 作为来源记录保存的实体工牌身份；跨设备导入时据此显示明确警告。

只包含已提交状态。导出前正常退出小程序，让待保存偏好完成提交。当前对话、录音、
网页未保存编辑、运行中的计时器，以及仅在内存中的卦象/定位历史不包含在内。
固件、内置音效、分区表、PHY 校准、eFuse 与无源 NFC 标签不导出也不还原。

网页备份保存每张工牌当前有效的提交存档，不包含失效旧存档中的历史残留。

## 在配置页导出

1. 用 Chrome/Edge 打开 `configure/index.html` 并通过 USB 连接，或连接工牌热点后打开
   `http://192.168.4.1`。
2. 先退出正在运行的小程序，再打开“07 配置导入/导出”。
3. 两次输入相同的新密码，长度 12–256 字符。
4. 点击“导出全部配置”，保存浏览器下载的 `.aipcfg` 文件。
5. 分开私下保管文件与密码。密码无法找回；没有事先备份，已擦除数据无法事后恢复。

设备一次性生成 NVS 快照，再按有界数据块传输。网页读取五张已提交工牌，校验每个区域
长度和 SHA-256，在浏览器中加密后启动本地下载。导出不写 Flash。文件落盘后的重名策略
由浏览器处理；不要分发或提交备份文件（仓库已忽略 `*.aipcfg`）。

## 在配置页导入

1. 先安装兼容的带工牌存储区固件，再重新打开当前固件内的配置页；旧标签页必须刷新。
2. 在第 07 节选择 `.aipcfg` 文件并输入原密码。
3. 点击“导入并覆盖配置”。页面在发送任何还原数据前，先在本机认证、解密并完整校验。
4. 确认覆盖**全部**设置与五张工牌。
5. 页面先用同一密码导出目标设备当前配置，下载
   `AI-Passport-before-import-....aipcfg`。确认浏览器已保存这份恢复文件后，再授权写入。
6. 保持供电和浏览器连接，直到工牌存档及 NVS 字节校验完成。随后工牌自动重启。
   手机热点可能因为恢复 Wi-Fi/热点状态而断开。

密码错误、文件损坏/截断、未知工牌格式或固件不支持时，在导入开始前停止。另一块实体
工牌只要固件提供相同备份能力和工牌布局即可导入；页面会在生成目标设备恢复文件前，
明确提示这是完整迁移。工牌资料沿用已有双存档事务和回读校验。NVS 最后恢复：固件先在 RAM 收齐所有
数据块并校验 SHA-256，再停用 NVS，仅擦写固定 NVS 分区；成功后才安排重启。协议不接受
应用、音效、分区表、PHY 或 eFuse 地址。

跨设备会复制五张工牌、Wi-Fi/AI 凭证、配对记录、应用状态和云端身份。两台设备同时
使用复制的云端身份可能冲突，与硬件或服务绑定的配对也可能需要重建。请把它当作主动
完整迁移：阅读警告、保留目标设备的 `before-import` 文件，并按需停用或重新配置来源设备。

六个逻辑目标无法整体原子提交。工牌写入阶段中断时，部分位置可能已经是导入值；
NVS 开始写入后若 USB/供电/写入/校验失败，不要擦除或继续普通配置。重新连接，使用刚才
下载的 `before-import` 恢复文件和相同密码导入。恢复需要用户执行，不是自动回滚。

## 加密与热点兼容

网页备份采用格式 1：AES-256-GCM 认证加密，随机 16 字节盐和 12 字节 nonce，
PBKDF2-HMAC-SHA-256 执行 600,000 次。来源设备身份、NVS、工牌资料、每项素材的标签/长度/
SHA-256 和内容都在加密载荷中，外层算法头作为附加数据参与认证。密钥派生/解密前严格
检查大小、版本和 KDF 参数。

安全上下文优先使用浏览器 WebCrypto。工牌热点是本地普通 HTTP，WebCrypto 可能不可用，
因此页面内嵌锁定版本的 `@noble/ciphers` 2.4.0 与 `@noble/hashes` 2.4.0 MIT 回退实现；
随机数仍来自 `crypto.getRandomValues`。源码/许可证记录在 `configure/vendor/`，不使用 CDN。

通过 USB 会话或随机 WPA2 热点授权的配置页，可在用户明确导出时请求不透明 NVS 快照。
这比普通表单读取权限更强，但页面不会显示快照或凭证，而是立即放入加密文件。执行时请
关闭其他配置页面，使用可信的仓库离线页或固件内嵌页，不要加载不可信脚本或扩展。

## 验证

- `tests/test_config_backup_ui.cjs` 验证实际浏览器 AES-GCM/PBKDF2、完整工牌素材、
  严格结构校验及篡改/错误密码拒绝。
- `tests/test_config_backup_flow.cjs` 验证恢复文件下载早于写入、NVS 有界分块、最后提交，
  取消路径不发送还原数据，跨设备迁移显示凭证/身份复制警告。
- 固件构建验证网页备份协议和内嵌页面。

实机还必须分别验证 USB 导出/导入、热点手机导出/导入、五张工牌/图片、当前显示位置、
Wi-Fi/AI/应用设置、重启、跨设备警告与迁移，以及在私有整机备份保护下验证中断导入恢复。
主机测试和编译成功不代表设备验收通过。
