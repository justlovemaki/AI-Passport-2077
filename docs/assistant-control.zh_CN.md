# 小智设备控制（2.6.23）

## 当前新增能力

现在共 19 个工具。2.6.23 扩展原有提醒工具，增加资料读写及系统操作工具；下文旧版本段落保留为历史记录，以本节为准。

- 提醒最多 8 条，支持 1～86400 秒倒计时、北京时间钟点、指定日期、每日或指定星期重复。创建前需联网校时；存入 NVS，退出小智、重启或断电不会删除。关机期间不响铃，开机校时后恢复；过期一次性提醒补响，错过超过 10 分钟的重复提醒跳到下一次，已经响起但未确认的提醒保留。多个到期提醒逐条显示，OK 确认。提示音固定 90%，不修改程序音量偏好。
- `self.reminder.set`：`seconds` 或 `time:"HH:mm"` 二选一；钟点可选 `date:"YYYY-MM-DD"` 或 `weekdays:[1..7]`（周一为 1，周日为 7），两者互斥。文字最多 32 字/96 字节。`get` 返回编号、下次时间、剩余秒数与重复星期；`cancel(id)` 只取消指定编号。
- `self.badge.get_profile(number?)`：省略编号读取当前工牌，返回姓名、部门、职位、是否可编辑和版本。`self.badge.update_profile(number,revision,field,value)`：修改 `name`、`department` 或 `title`；必须先读取版本，网页同时修改时拒绝覆盖旧资料。
- 资料文字及屏幕像素一起双备份提交。姓名最多 20 字，部门/职位最多 24 字；屏幕两行，放不下显示省略号，完整文字保存在资料中。只支持 V4 资料，旧版请先在配置网页重新保存。使用已有中文字库，缺字会拒绝修改；头像、二维码、品牌及底部艺术字资源保持原样。
- `self.system.action(action)`：`home` 直接回首页；`shutdown` 关闭联网、音频和屏幕并深度休眠，上键唤醒。这是软件休眠关机，物理电源键可真正断电。系统操作结束当前对话。

示例：“每天下午三点提醒我喝水”“工作日上午九点提醒我开会”“十分钟后提醒我休息”“取消编号 2 的提醒”“把当前工牌的职位改成产品设计师”“返回首页”“关机”。

验证入口：`test_badge_alarms.c`（定义 `BADGE_ALARM_SERVICE_TEST` 可加持久服务故障测试）、`test_profile_text.c`、`test_profile_edit.c`、`test_profile_store.c`、`test_xiaozhi_tools.c`。`BADGE_ASSISTANT_DEVICE_PROBE` 仅用于台架，会添加测试提醒并用定时器从深睡唤醒；正式版必须关闭。工具目录仍使用只读 JSON 与预分配发送缓冲，主机验证目录低于 7 KiB、构建分配低于 1 KiB。

## 历史行为：2.5.x

沿用现有 MCP 连接，提供状态、小程序、音效、二维码、工牌、亮度、小智音量、
电台和定时提醒共十四个工具。复用已有 Wi-Fi、资料、音量及资源设置。
语音识别和工具选择仍需连接已配置的小智服务，服务端需支持设备 MCP 工具。

| 工具 | 参数与行为 |
| --- | --- |
| `self.get_device_status` | 音量、真实 Wi-Fi 状态、亮度、已配置工牌编号、当前工牌、二维码状态和上次动作结果（0 等待/初始，1 成功，-1 失败）。 |
| `self.apps.open` | `app` 为 `zen-muyu`（木鱼）、`leo-radio`（城市电台）、`voice-keychain`（音效钥匙扣）、`cyber-yao`（摇卦）或 `muse`。电台和 Muse 要求 Wi-Fi 已连接。 |
| `self.audio.search` | `query` 按标题或分类匹配，`offset` 可选；每页最多六条，返回真实音效编号。关键词为空可分页浏览。 |
| `self.audio.play` | `clip_id` 使用搜索结果中的编号，打开对应分类并播放指定音效。 |
| `self.badge.show_qr` | 显示当前工牌已上传的二维码，未上传时返回工具错误。 |
| `self.badge.switch` | `number` 为 1～5，仅允许已配置工牌，切换后回首页。 |
| `self.display.set_brightness` | `percent` 为 20/40/60/80/100，沿用系统设置保存，对话继续。 |

所有参数严格校验；未知工具、无效参数不产生动作。资源缺失、已有动作等待处理时
返回工具错误。音效先搜索再播放，使用真实资源编号，不猜测编号。

切换页面的指令先返回接收响应，传输层接受响应后才提交给主任务，避免停止小智时
丢失回复；此类响应不冒充执行完成。音量、亮度、提醒设置/取消属于原地操作，
会立即唤醒主任务，等待最多两秒后返回 execution=completed/pending/failed。
原地操作的回复若发送失败，操作可能已经生效，重试前应查询状态；切换指令的
发送失败则取消尚未提交的指令。断线和退出会取消仍未执行的指令。
命令槽和导航快照由临界区保护，语音任务不直接读取导航对象或访问 LVGL。

导航任务重新检查资料状态，停止小智，等待麦克风、编解码器及网络资源释放后才删除
页面、启动目标小程序。停止失败时保留现有页面；目标启动失败时尝试返回首页。
执行阶段失败会记录日志，小智会话结束后无法再语音报告失败。亮度调整保留对话；
切换页面或小程序会结束对话，进入目标程序后不支持后台继续听语音指令。

## 2.5.0：音量、姓名、电台与定时提醒

- `self.xiaozhi.set_volume(percent)`：0～100，0 为静音。只改小智回复音量，
  使用原有延迟保存和退出写入机制；电台、木鱼、音效的设置保持独立。
  状态响应标记 `volume_scope=xiaozhi`，不应把该工具解释为全局音量。
- `self.get_device_status` 增加 `battery_percent`（-1 表示不可用）、
  `active_badge_name` 和 `badge_names`。电量为最近一次采样，清醒时约每 30 秒更新，息屏时暂停采样。
- `self.badge.switch` 接受 `number` 或 `name`，只能选一种。
  姓名必须与已保存资料完全一致；重名时要求用户指定编号。执行前重新校验姓名，
  防止配置页修改资料后切换到错误身份。
- `self.radio.search(query, offset)` 分页搜索现有精选电台，每页最多六条；
  `self.radio.play(station_id)` 使用搜索返回的真实编号。直接启动对应频道，
  跳过首次城市定位等待。在线城市目录中的额外频道暂不在语音搜索范围。
- `self.reminder.set(seconds, text)` 设置一条 1～86400 秒倒计时，文字最多 32 字、
  96 UTF-8 字节；已有提醒时拒绝覆盖。`self.reminder.get` 查询剩余时间，
  `self.reminder.cancel` 取消。均保留当前对话。

提醒由主任务持有，基于单调时钟，退出小智、切换小程序、轻睡眠期间继续计时。
到期后唤醒屏幕，先停止当前小程序并等待音频资源释放，再回首页显示主题色提醒层。
若应用停止失败则重试，不让提示音与仍在运行的音频并发。倒计时检查约每 250 毫秒
执行一次，息屏时约每秒一次；停止网络/音频任务可能增加几秒延迟，因此不用于精确计时。

提示音固定使用 90% 音量，三声后停止，随后恢复共享芯片原音量并休眠音频；
不改任何程序的音量偏好。OK 可关闭提醒并回到首页，不会自动恢复被中断的播放。
提示音任务分配失败时仍显示文字。提醒只保存在本次开机的内存中，重启/断电后清除，
暂不支持每日重复或具体钟点闹钟。文字使用现有 GB2312 字体，生僻字与表情可能无法显示。

## 2.5.1：工具进度字幕与完成回执

实机云端测试捕获到服务端下发 `% self.xiaozhi.set_volume...` 作为 TTS 句子事件，
随后才下发正常聊天回复。前者是工具调用进度标记，旧版直接进入了字幕，并非 C 格式串
忘记替换参数。字幕入口现在仅过滤完整的 `% self.方法名...` 标记（也接受省略号），
不删除普通百分比、正文中的方法名或对 `%s` 的解释。语音和最终回复保持原有路径。

工具说明明确：指定电台或音效的 play 已包含打开应用，不应先调用 apps.open；
组合任务应先完成设置，最后才切换应用。工牌编号与姓名的互斥约束也写入 schema。
原地操作的完成回执解决紧接着查询读到旧值、连续提交第二条收到忙碌错误的常见时序。
等待超时仍返回 pending，不能当作完成；切换应用仍会结束会话。

`tests/test_xiaozhi.c` 覆盖进度标记和正常百分比/代码文本的区别；工具测试覆盖唤醒、
完成、取消、失败和过期回执。`BADGE_TOOL_CLOUD_PROBE` 为临时云端诊断开关，
使用固定合成音频，不读取真实麦克风。诊断原文仅保存在本地私有日志，生产必须关闭。
探针音频头 cloud_probe_pcm.h 放在构建目录，不属于发布资源，也不会嵌入正式固件。

## 2.6.3：随机音效与再次唤醒

`self.audio.play_random(query)` 直接从匹配的音效中随机选择并播放，`query` 可省略或留空以搜索全部，也可限定分类／标题关键词。不需要先搜索或打开应用。候选多于一条时排除上一次随机选择；仅一条时允许重复；无匹配返回错误，不跳转页面。返回真实编号、标题和分类，沿用确认发送后再执行的流程。指定编号播放保持不变。

音效库初始化完成且没有排队或正在播放的音效时，导航任务停止播放器、释放解码器和任务栈，保留列表界面，再恢复后台唤醒。按键操作时先停止唤醒检测，再恢复播放器。排队请求同样占用音频，旧请求完成不能清除新请求的占用。播放结束或手动停止后可再次说“你好小智”；识别后退出音效库进入小智，关闭对话返回原来的首页或小程序列表。播放期间仍暂停唤醒，木鱼与电台保持原来的互斥策略。

2.6.3 验证：主机测试覆盖随机结果范围、分类过滤、多候选不连续重复、未知参数／空结果拒绝，以及取消旧请求不能释放新音效的占用。硬件探针使用真实麦克风采样、模拟唤醒触发，验证音效列表空闲恢复、播放期间互斥、手动停止后恢复、三次自然播完后再次唤醒；五次启停后的空闲堆内存与基线相同。真实说话的唤醒率与云端对随机指令的工具选择仍需实际交流验证。

## 直接切换目标页面（2.6.6）

语音打开小程序、播放指定或随机音效、播放指定电台、显示二维码、切换工牌时，不再
中途绘制首页。导航任务停止并等待音频任务退出时保留小智画面，随后在同一次 LVGL
锁内销毁旧页面、创建并绘制目标页面。切换工牌只绘制一次所选工牌。音量、亮度、
提醒等原地操作仍保留当前对话。

目标页面准备失败时，重新启动现有对话的后台任务；已创建小程序页面但启动失败时，
停止该小程序并恢复首页。等待任务退出的操作均在 LVGL 锁外执行。

可选控制测试会统计每条指令的首页绘制次数、检查所绘制工牌编号，并模拟准备失败、
启动失败。发行固件必须关闭测试。测试为了检查息屏提醒会临时关闭后台唤醒，结束时
恢复原设置。

实机已通过三个小程序入口、指定/随机音效、二维码、指定电台、按编号/姓名切换工牌。
成功操作的首页绘制计数均为零；切换工牌则只绘制一次目标工牌。模拟准备失败能恢复
对话，模拟程序启动失败能恢复首页。原有音量保存、发送失败取消、提醒、息屏唤醒和
设置恢复也通过。测试使用真实 UI、音频生命周期及设备工具分发，关闭云端连接；未
使用相机测量物理屏幕的逐帧时序。
