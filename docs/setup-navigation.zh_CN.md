# 首次配置与返回导航 — 1.9.0

当前跳转规则（2.2.0）：首页上键直接打开小程序列表，首次配置页也适用；列表记住首页或员工终端作为返回上一级。
工牌资料页直接显示热点引导，OK 在本页开关热点。以下配置、留白与历史验证部分保留 1.9.0 记录；返回策略描述当前实现。

五个位置都没有已保存的工牌时，首页显示配置引导，并自动请求开启带密码的配置热点。已有工牌的设备仍直接展示工牌。清除最后一张已配置工牌后，也会再次进入引导，不删除其他设置。

引导包含热点名称与密码、`http://192.168.4.1`、保存和显示工牌的步骤，并提醒手机提示“无互联网”时保持连接。下键进入菜单，上键进入设置；热点关闭或启动失败时，OK 可重新开启。首次配置期间暂停十分钟空闲关闭规则，仍允许手动关闭热点。保存第一张工牌后恢复普通空闲规则，重新计时十分钟，保持当前配置连接。

从系统设置或工牌资料进入网络引导，也会按需打开热点。热点已开启时不会更换密码或断开客户端。浏览器中保存所需工牌；如果编辑的不是当前显示位置，保存后再点 **显示这张工牌**。

## 按场景返回

长按 OK 请求返回；工牌首页仍用此操作打开工牌切换列表。不增加两档长按或组合键。

| 所在页面 | 返回行为 |
| --- | --- |
| 员工终端、小程序列表、系统设置、工牌切换及二维码 | 直接返回记录的父页面；二维码保留短按返回 |
| 电台设置/音量/城市/定时，以及音效片段/音量 | 直接返回应用内部上一层，不经过退出弹窗 |
| 小程序根页面或小智对话，入口与工牌是不同去向 | 选择明确命名的入口页面、回到工牌或继续 |
| 安全快捷启动，入口本来就是工牌 | 直接返回，不提供重复目的地 |
| Muse 录音/本地等待，或活跃的小智会话 | 确认中断，默认选继续；只有工牌出口时显示两项 |

目的地明确写为小程序、员工终端、小智设置或保留的卦象，不再笼统使用上一页/首页。
普通导航选择默认返回入口；中断确认默认继续。上下选择，OK 确认，再次长按 OK 取消；
继续也是可见的取消选项。弹窗不超时执行退出，也不再叠加第二次确认。
电台/音效退出说明播放会停止。弹窗打开本身不暂停播放、木鱼自动敲击或云端工作。
Muse 退出只取消本地录音/等待，已提交的云端任务仍可能继续。
设置仍遵守原来的即时保存或 OK 确认保存规则，不为内存保留的卦象虚构未保存或丢失提示。

返回查询不产生副作用。应用查询失败时延后处理，不把未知内部页当成应用根页退出。
弹窗保留来源、目的地及应用身份；其中任意一项或内部层级变化后，旧选项失效。
请求完成不会使未变化的返回路径失效。弹窗打开时，非紧急语音唤醒和助手命令不能替换页面；
提醒沿用原有优先级，由生命周期拥有者处理并关闭弹窗。

弹窗打开/关闭及返回一层会消耗触发按键的松开和延迟单击/双击尾事件，直到下一次新按下。
已交给应用的按下事件，其松开仍送回应用一次，避免丢失 Muse 上键释放；弹窗中的新上键
不会开始录音。退出显示进度，任务停止成功后才删除 UI；失败保留页面，提供重试目的地，
默认选留在当前页面。停止失败后留在页面不承诺部分停止的任务会恢复。

主机覆盖位于 `tests/test_badge_navigation.c`、`tests/test_badge_return_input.c`、
`tests/test_radio.cc`、`tests/test_voice.c`、`tests/test_xiaozhi.c` 与 `tests/test_menu_font.py`。
在具备 gcc 的 POSIX 主机运行 `python3 tools/render_return_host.py`，在实际木鱼页面上
渲染 LVGL 弹窗，检查两项/三项选项、目的地名称、安全默认项、进度/重试布局，
并在 32 KiB 池中循环创建/
销毁 200 次。RGB565 预览位于 `build/return-ui/`；这不验证实体按键、音频或云端取消。
实机需验证播放中内部返回、两个退出去向、快捷启动的单工牌出口、Muse 松键/取消、
小智返回卦象、停止失败重试、提醒抢占，以及反复创建/销毁页面。
