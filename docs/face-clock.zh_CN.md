# 小智表情与通用时钟

2.6.17 提供四套可切换风格：圆萌精灵、男生头像、女生头像和公路之王。男生采用圆润光头、柔和反光和小高光，女生采用圆弧短发、发夹与耳饰；两版使用统一的眉眼间距、小鼻子与圆润脸型；圆萌精灵使用圆脸、短耳朵、小卷毛、腮红和小爪子的角色，支持小智全部 21 种情绪标签，每种有三款专属造型，每套 63 款，四套共 252 款。原创 SVG 源文件位于 `assets/images/xiaozhi-face/`。安装 Pillow 后，运行 `python tools/generate_face_assets.py` 可重新生成已纳入源码的 A8 透明度图片。离线转换器只接受这些素材实际使用的 SVG 元素。固件构建直接使用生成的数组，不需要 SVG 或 GIF 解码器。

裁剪空白、去重并无损压缩后的透明度图片共 136,196 字节，不含图片描述符：三套头像轮廓、光头高光、男女头像的鼻耳细节、女生发型与配饰；人像共用 26 种眼睛与 24 种嘴形，精灵保留自身部件。眼睛涵盖 21 种情绪、眨眼和四种新增样式；嘴形涵盖 21 种情绪和三档说话动作。另有八种共用装饰。可运行 `python tools/draw_face_sources.py` 重建 SVG 源文件，运行 `python tools/draw_abstract_sources.py` 重建男女头像，然后再生成数组。颜色来自工牌强调色、文字色和背景色，并自动选择对比度较高的五官颜色。情绪改变时刷新一次角色区域，普通嘴部和眨眼变化只重绘小区域，不增加全屏动画缓存或动画帧队列。使用界面已有定时器，息屏时随 LVGL 停止，退出页面前删除。

云端 `llm.emotion` 为以下每种标签选择一个专属的三款造型池：`neutral`、`happy`、`laughing`、`funny`、`sad`、`angry`、`crying`、`loving`、`embarrassed`、`surprised`、`shocked`、`thinking`、`winking`、`cool`、`relaxed`、`delicious`、`kissy`、`confident`、`sleepy`、`silly`、`confused`。使用墨镜、眼泪、爱心、腮红、思考手势等区分造型。倾听、思考和错误状态优先；未支持的情绪回退为普通表情。说话时的嘴形跟随最近一次成功写入的 PCM 音频能量，不跟随字幕进度或服务器的说话通知。每次成功写入后设置 100 毫秒有效期，以覆盖现有 16 kHz 下六个 240 采样 DMA 缓冲区。即便服务器仍标记说话，超过有效期也会在下次界面刷新时恢复当前情绪的静态嘴形。暂停、打断及状态切换会结束说话动作。大笑或惊讶的静态嘴形本身可以张开；自动眨眼不会替换墨镜或单眼眨眼。这是振幅可视化，不是逐音素对口型；实际声画结束时间仍需扬声器和屏幕联合测量。

语音任务在内存中为每种情绪维护轮换池，三款用完后才重新装入，下一轮首次选择会避开上次最后一款。同一句回复中重复收到相同标签时，保持原造型且不消耗池中的选项；新一轮对话或情绪明确切换为其他标签时，才允许重新选择。会话销毁或重启后清空历史。缺少情绪字段的消息被忽略，未知的非空标签回退为普通表情。界面刷新定时器不会反复随机选款。眼睛、嘴巴偏移以及爱心、眼泪、星光和手势位置均属于选定造型；音频过期后恢复同一款造型的静态嘴形。

通用顶部独立于 Wi-Fi 读取本地系统时钟，只显示 24 小时制北京时间（UTC+8）`HH:mm`，不显示日期。每次 Wi-Fi 获取地址后，通过 `ntp.aliyun.com` 异步 SNTP 发起 UTC 校准；重连会再次发起校准。受版本控制的默认配置取消 SNTP 随机启动等待，并保留每小时更新。收到有效响应后立即修正本地时钟；请求等待或失败不会清空已有时间，也不会阻塞显示。RTC／高精度系统时钟在离线和休眠期间继续计时。尚未设置时间时显示 `--:--`；完全断电后的冷启动若没有新的时间来源，就无法恢复当前真实时间，不会把保存的旧时间戳当成当前时间。不修改全局时区或已保存工牌。复用每秒状态检查，仅在文字改变时刷新，息屏跳过绘制。

主机测试覆盖首次连接／重连校时请求、离线显示与跨日、未校时、未知情绪、静音和打断、音频过期、32 位单调时钟回绕。同时测试全部标签的独立映射、过期后恢复各自静态嘴形及未知标签回退。绘图检查包括顶部最大内容（100% 电量、工牌序号、Wi-Fi）、校时前后、没有新网络消息时自动闭嘴及反复进出页面。编译及主机测试不能代替实际声画同步和云端识别验证。

在设置 → 小智 AI → 表情风格按 OK 切换「圆萌精灵 / 男生头像 / 女生头像 / 公路之王」。选择保存到 NVS 的 `xiaozhi/face_style`，重启后恢复；旧固件升级默认沿用圆萌精灵。写入在导航任务中、LVGL 锁外进行，绘制只读原子缓存。读不到或遇到非法值回退默认风格，保存失败保留原选择。

进入思考状态后，思考表情最少展示 900 毫秒；提前开始回复时只保留思考眼神，嘴形立即跟随 PCM，字幕与声音不等待。900 毫秒结束后显示最新情绪。暂停、重新倾听、错误和绑定状态会立即取消保留。该时间是视觉下限，界面刷新可能再增加一个刷新周期。主机测试覆盖跨计时回绕、取消、NVS 保存失败和四种风格的 252 个渲染结果，实机音画体验需实际对话验证。

风格编号保持兼容：0 为圆萌精灵，1 为重新设计的男生头像，2 为女生头像，3 为公路之王。设置依次轮换这四种风格，保存后重启恢复；已选择旧涂鸦人像的设备升级后使用新版男生头像。女生独有的轮廓、发型、发夹与耳饰和人像共用五官组合，无需为每种情绪存储整张图片。

对话页快捷操作：长按上键依次切换圆萌精灵、男生头像、女生头像、公路之王并保存，不停止语音任务或重建对话界面。长按下键直接进入小智设置，沿用停止/复用连接流程；从该设置入口选择返回上一页或开始对话会回到小智，对话页原来的返回目标保留。短按上下调音量，OK 控制开始/暂停/打断。长按 OK 使用[按场景退出选择](setup-navigation.zh_CN.md)，明确显示目的地，活跃会话默认继续；设置页本身直接返回对话。底部提示使用同一行，字库覆盖和总宽度均由主机测试检查。

2.6.15 为人像单独重画全部 21 种嘴形和圆弧眼睑，重新搭配人像专用的三款情绪变体，不再复用精灵嘴形。缩短鼻部、减少夸张眉眼和腮红，泪滴缩小至独立部件；有趣表情仅第三款保留笑泪。男生光头的柔光和小高光为静态透明度层，随主题变色，不增加高频动画定时器或音频等待。

2.6.16 新增「公路之王」（保存编号 3），按用户提供的参考图重绘宽圆脸、蓬松短发、横眉、小眼睛和收敛嘴形；周围场景与参考图上的文字不属于头像素材。肤色、头发、五官、鼻线、衣领、腮红和泪滴全部从当前工牌主题计算，选择对比度较高的五官颜色，不固定使用参考图原色。独立绘制 21 种情绪、三档小幅说话嘴形，使用人像三款组合规则。运行 `python tools/draw_round_sources.py` 更新 SVG，再运行通用转换器。左右眼分开裁剪并去重，去掉透明间距，保留原像素；此版本不在设备上解压或解析 SVG；2.6.17 改为下述逐行无损解码。对话中长按上键依次切换四种风格并保存，长按下键进入小智设置。

2.6.17 将透明度数据按行进行无损游程压缩，不值得压缩的小图保留原始 A8。每行带偏移索引，只解码需要重绘的行；每次绘图会话只分配一行（最多 160 字节像素，另含 LVGL 管理开销），不缓存整张脸，也不改变灰度、主题颜色或表情组合。252 张完整渲染画面与 2.6.16 逐像素一致。退出页面清理解码器及其头信息缓存。

输入字幕使用独立的两行区域，保留到下一次识别，不再被回复瞬间替换；恢复倾听时也保留。长句从开头显示，每三秒翻动两行，到末页停留后循环。下方回复保持独立音频时钟和逐字显示，声音与回复字幕不等待输入阅读。错误和绑定页面隐藏对话区域。

## 公路之王默认神态（2.6.32）

仅公路之王调整 neutral／默认表情：变体 A、B 使用愤怒神态，C 使用自信神态。沿用三变体轮换，每轮完整的默认表情选择中为两次愤怒、一次自信，并非固定时间占比。明确情绪、思考和错误状态覆盖、音频驱动嘴形保持原有含义；自动眨眼保留愤怒眉形。其他头像风格不变。

2.6.33 将公路之王的左右眼统一为配对几何形状，并在像素层镜像，避免小尺寸下两眼粗细不一。眨眼改为双眼同步；愤怒／自信映射保留，其他头像资源不变。

## 双眼与泪滴配对（2.6.34）

四套风格统一使用左右镜像眉眼；眨眼为双眼同步，哭泣与笑哭均显示两滴等高、相同大小的眼泪，并跟随眼睛偏移。汗滴也改为左右配对。对称处理在离线素材生成时完成，不增加设备运行时镜像计算。SVG 左半边为绘制参考，生成器也统一瞳孔高光和泪滴像素。「公路之王」保留愤怒／自信默认映射，每套风格仍保留 21 种情绪及各 3 个不同造型。
