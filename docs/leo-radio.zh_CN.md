# LEO Radio 集成 — 2.0.2

第三个工牌小程序基于 [leo0183/leo-radio](https://github.com/leo0183/leo-radio)，参考提交 `e28b8adafb2ca95e386e8b6e7db0db042cf09523`。电台共用工牌 Wi-Fi、音频设备、游戏生命周期及五种主题颜色。木鱼和语音钥匙扣继续保留，24 个音效包 / 726 段精选音效与所有 Flash 分区地址不变。

## 使用

工牌首页 → OK → 小程序 → 城市电台。连接已保存的 Wi-Fi 后，根据网络位置查找电台并开始播放。本地结果与 57 个内置精选 MP3 频道合并并去重；本地查询失败时仍保留精选列表。这是网络电台；FM 刻度为视觉转盘，硬件不接收调频无线电信号。

| 操作 | 功能 |
| --- | --- |
| 上 / 下 | 上一个 / 下一个电台 |
| 短按 OK | 暂停 / 继续 |
| 长按上键 | 电台设置 |
| 长按下键 | 停止播放 |
| 长按 OK | 设置子页直接返回一层；根页面存在不同去向时选择小程序、工牌或继续 |

退出弹窗说明离开会停止播放；打开或取消弹窗本身不停止直播。入口只有工牌的快捷启动直接退出，不提供重复目的地。详见[按场景返回规则](setup-navigation.zh_CN.md)。

设置包含音量（0–100%，每次 5%）、自动定位或七个预设城市、15/30/60/90 分钟定时停止。上下选择，OK 确认。定时只停止电台，不关闭工牌。音量、城市及选中的电台保存在独立的 `badge_radio_v1` NVS 空间；退出会清除定时。Wi-Fi 沿用现有 USB 或热点配置页，无需单独账户或电台网页。

背景、面板、刻度、音量振幅条、标题和文案跟随当前工牌主题，也支持自定义配色。全部小程序复用首页相同的顶部栏：AI Passport、已连接 Wi-Fi 图标、电量百分比及分隔线。Wi-Fi 配置仅保留在工牌系统设置中。动态条反映解码后 PCM 的实际振幅，不是频谱分析。未知频率的电台显示 NET，不虚构频率。

## 集成及内存

- `radio_app.cc` 接入游戏框架。UI 和刷新定时器在 LVGL 锁内操作，后台通过同步快照更新状态，不直接访问界面对象。
- 单个 10 KB 栈工作任务顺序执行目录查询、HTTP 读取、MP3 解码、单声道混音及播放。取消后关闭流资源，再删除屏幕；停止超时则保留页面供再次退出。
- 锁定 `espressif/esp_audio_codec` 2.5.0，仅注册 MP3 解码器。PCM 缓冲为 4,608 字节（一个最大立体声 MP3 帧），输入为 1,024 字节。不支持的格式会正常退出播放。
- 目录响应按最多 4 KB 的单条对象拆分、解析，限制总字节数和请求时长，跳过超大条目，不在内存中保留完整目录树。
- 木鱼 4,480 字节音色缓存和语音钥匙扣 3,420 字节包/PCM 缓存改为游戏运行时分配，任务停止后释放，避免无 PSRAM 的 ESP32-C3 常驻存放未使用的游戏缓存。
- 不启动原项目独立的 Wi-Fi 管理器、电源控制器或视频彩蛋；网络配置、休眠与返回导航由工牌管理。

## 来源与限制

上游 MIT 许可保留在 `assets/radio/LICENSE.txt`，来源见 `assets/radio/SOURCE.txt`。解码器采用仅限 Espressif 产品使用的 Espressif Modified MIT 许可，完整声明位于 `assets/radio/ESP_AUDIO_CODEC_LICENSE.txt`。目录和 IP 定位依赖第三方网络服务；定位是近似值，电台地址及可用性可能变化。支持直接 MP3 直播，不支持 HLS/AAC。公共目录标题可能简化以适应内置字体。源码和固件均未打包或录制广播音频。

## 验证及安装

`./tools/validate.sh --static` 覆盖频率解析、单声道转换、定时边界、分层导航、分段/超大 JSON 对象及已有工牌与音效测试。`python3 tools/render_radio_host.py` 用实际生产 LVGL 界面渲染四套预设主题和五种页面，并在相同 40 KB LVGL 内存池下循环创建/销毁 100 次。

`-D BADGE_RADIO_DEVICE_PROBE=ON` 为可选台架测试，会注入导航事件。**正常固件必须设置 `-D BADGE_RADIO_DEVICE_PROBE=OFF`**，尤其是复用测试构建目录时。交付镜像关闭此选项。

从 1.9.1 更新使用分段写入引导、分区表和应用，音效分区无需改写。合并镜像用于空白设备；在已配置工牌上整包覆盖会改写包含用户数据的间隙。私有备份必须放在交付目录之外。

## 2.0.1 — 小程序、统一顶部与按键响应

员工终端入口改名为 **小程序**。电台设置仅保留音量、城市、定时停止；Wi-Fi 配置统一在工牌系统设置中。首页、木鱼、语音钥匙扣和电台复用 `badge_header.c`，标题、Wi-Fi 图标、电量和分隔线位置完全一致。运行小程序时，系统继续刷新网络状态。

上下键短按在新增的 BSP 松键事件上响应，不等待单击/双击判定；收到实体边沿后忽略重复的单击/双击事件，长按松开不会误切台。实机注入连续八次切台和六次设置项移动，覆盖这些路径。

电台界面跳过未变化的文字及样式，只刷新影响区域。主机渲染测得静止画面刷新 0 像素，振幅更新为 6,360/76,800 像素，设置选择为 10,176/76,800 像素。已连接 MP3 流的读取超时缩短到 100 毫秒，正常处理 EAGAIN，因此取消检查不再等待原来的 2.5 秒读取超时。新电台建立连接仍取决于服务器和网络。

主机测试逐像素比较四种页面顶部 29 行，覆盖四套配色、Wi-Fi 连接/断开和电量未知/0/100%，全部一致。电台 UI 循环 100 次后剩余 16,032 字节（循环前同为 16,032），40 KB 池峰值使用 21,368 字节。实机注入松键事件到选中状态更新为 1–59 毫秒，六次设置项移动为 26–36 毫秒。该计时覆盖事件处理和状态更新，不包含实体按键消抖或屏幕扫描输出测量。人工按键手感、音质和长期运行仍需体验验收。

## 2.0.2 — 精选频道与列表字形

电台列表保留 57 个内置精选 MP3 频道，并与最多 10 个本地结果合并。同一直播的 HTTP/HTTPS、Qingting/Qtfm 域名别名按直播 ID 去重。即使本地仅发现两台，也不会覆盖完整精选列表；本地目录不可用时仍保留精选频道。

候选来自 [公开电台目录](https://github.com/gaotianliuyun/gao/blob/master/radio.txt) 和原项目预设，逐项来源保存在 `assets/radio/STATIONS.txt`。2026-09-15 对 80 个候选抓取约 24 KB 短样本，57 个通过下载、MP3 编码识别与 PCM 解码检查，其余排除。频道名称依公开目录；短样本验证不代表节目内容核验或长期可用性。未将广播样本打包进固件或源码。

精选记录保存在 Flash 只读区；ESP32-C3 运行时目录共 4,252 字节（64 位主机测试为 4,264 字节），包含 10 个本地记录和最多 64 个索引，工作任务栈保持 10 KB。主机测试覆盖合并、别名去重、伪域名、容量、首尾循环及空结果恢复。

第二个小程序说明来自自动生成的 `VOICE_SUMMARY`；原字库扫描遗漏了生成器中的“个、类、段”。字体生成器现在包含该文本来源，并对实际生成说明和全部精选频道名执行字形覆盖检查。实际 LVGL 预览确认“24 个分类 / 726 段音效”完整显示。
